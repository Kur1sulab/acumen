鉴微 Acumen v1.1.0 —— Windows 绿色版
================================================

不需要安装任何东西。不需要 Python，不需要 pip，不需要联网。

用法
----
1. 把整个压缩包解压到一个你有写权限的目录
   （桌面、D 盘、U 盘都行；不要只解压一半）

2. 双击 acumen.bat

3. 浏览器会自动打开 http://127.0.0.1:7788/
   如果没自动开，手动在浏览器输入这个地址

4. 用完关掉黑色窗口即可停止

目录说明
--------
acumen.bat      启动器，双击这个
python\         内置的 Python 3.12.8 运行时（约 25MB），不用管
vc\             程序本体
README.md       完整功能说明
CHANGELOG.md    版本更新记录

安全说明
--------
· 只监听 127.0.0.1，局域网里其它机器访问不到
· 不发起任何外部网络请求，没有遥测、没有上报
· 数据全部保存在本机：C:\Users\<你的用户名>\.acumen\vuln.db
· 收件箱默认扫描 C:\Users\<你的用户名>\pentest-inbox 等目录

常见问题
--------
Q: 双击后窗口一闪就没了
A: 八成是压缩包没解压完整。重新完整解压一次。

Q: 提示端口被占用
A: 说明已经有一个实例在跑，直接用浏览器打开 127.0.0.1:7788 就行。

Q: 360 提示风险
A: 这是 Python 官方绿色版运行时的固有误报，程序本身没有任何网络行为。
   信任后放行即可。

Q: 想换端口
A: 命令行里跑 acumen.bat --port 7799
